## 按 rag-optimization-plan.md §9 分期路线图落地 RAG（已实现）

用户要求按方案文档一步一步实现 RAG。已完成三期 + 配套，全部代码落地 + 46 个测试通过 + 无回归。

### 新增 RAG 子系统 codebot/rag/
- `__init__.py`：导出接口
- `embedding.py`：EmbeddingProvider 抽象（OpenAIEmbedding + NullEmbedding）+ cosine_similarity + create_embedding_provider 工厂。复用现有 ProviderConfig，anthropic 协议无 embedding 端点时降级 NullEmbedding
- `chunker.py`：AST 分块（Python 按 FunctionDef/ClassDef）+ 滑窗兜底（其他语言）+ 超长函数二次切分（MAX_CHUNK_LINES=50, SLIDING_OVERLAP=10）。CodeChunk 有稳定点 ID（hash file:name:start_line）
- `qdrant_store.py`：QdrantCodeStore（默认嵌入式 path=".codebot/qdrant"，可选 url 连 Server）+ NullCodeStore。COSINE 距离、payload 元数据过滤、upsert 增量、delete_by_file。create_code_store 工厂自动降级
- `indexer.py`：IncrementalIndexer，mtime 粗筛 + hash 确认的两级增量索引。元数据持久化 .codebot/rag/file_index.json。同步维护 BM25 索引
- `bm25.py`：自实现 BM25（不引 rank-bm25 外部包，保持轻量），K1=1.5/B=0.75
- `fusion.py`：RRF 融合算法（reciprocal_rank_fusion，k=60）
- `reranker.py`：embedding 轻量重排（embed_rerank），演示两阶段检索思想，不引 CrossEncoder 重依赖

### 三期落地
- **第一期**：memory/semantic_recall.py（SemanticMemoryIndex）。recall.py 的 find_relevant_memories 加可选 semantic_index 参数，优先语义检索失败回退 LLM 选择器。app.py 懒加载注入
- **第二期**：tools/code_search.py（CodeSearch 工具）。完整链路：query embedding → Qdrant 向量召回 Top20 + BM25 关键词召回 Top20 → RRF 融合 → Top5。注册到 create_default_registry。app.py 的 _init_rag_code_search 初始化 indexer+embedder。不可用时返回"用 Grep"降级提示
- **第三期**：ToolRegistry 新增 search_deferred_semantic（embedding 语义匹配，失败回退关键词）。ToolSearchTool 加可选 embedder 注入。reranker.py 轻量重排
